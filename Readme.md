## ✨ Key Features

- ⚡ **Fully Responsive** – Mobile-first, looks great on all devices
- 🧠 **HTML5 & CSS3** – Clean and valid code structure
- ⌨️ **Typing Animation** – Powered by `Typed.js`
- 💡 **Easy Customization** – Modular and developer-friendly layout
- 🌙 **Dark Mode Ready** (optional add-on for next version)

---

## 📂 Website Sections

| Section           | Description                          |
|------------------|--------------------------------------|
| `✅ About`        | Personal bio, goals, background       |
| `✅ Interests`    | What you're passionate about          |
| `✅ Education`    | Academic background                   |
| `✅ Certifications` | Verified online achievements       |
| `✅ Experience`   | Work, internships, freelance gigs     |
| `✅ Projects`     | Highlighted work samples              |
| `✅ Skills`       | Tech stack with visual badges         |
| `✅ Resume`       | Downloadable or linked resume         |
| `✅ Contact`      | LinkedIn, email, GitHub, and more     |

## 🛠️ Tech Stack

- **HTML5** / **CSS3**
- **Vanilla JS** & `Typed.js`
- **GitHub Pages** for hosting
- **Shields.io** for dynamic badges
- **Responsive Design Techniques**
